# BookClub

Сайт для книжных клубов. У каждого человека есть своя полка книг (хочу прочитать, читаю, прочитал), книги можно оценивать и рецензировать, а в закрытых клубах следующую книгу выбирают голосованием, где никто не видит, кто за что проголосовал.

Это учебный проект на ASP.NET Core. Рабочая версия: https://bookclub-lanq.msk1.amvera.tech

## Что умеет сайт

Регистрация и вход выдают токен JWT, пароли хранятся в виде хэша BCrypt. В каталоге можно смотреть книги и добавлять свои, а на личной полке отмечать статус и оценку. К книге можно написать рецензию с оценкой от 1 до 5, по желанию анонимную: имя автора тогда видит только админ сайта, для модерации.

Клуб создаёт любой человек, остальные в него вступают. Внутри клуба открывается отбор: несколько книг на выбор и срок голосования. Один человек голосует один раз, пока отбор идёт, распределение голосов не видит никто («запечатанный конверт»), а после закрытия, вручную или по таймеру, результат вскрывается. Кто за что голосовал, не хранится вообще: в таблице голосов нет столбца с пользователем, а факт участия записан отдельно.

У админа сайта есть панель: общая статистика, поиск и фильтры по пользователям, блокировка и смена ролей, модерация рецензий с пометкой подозрительных и поиск дубликатов в каталоге.

## Технологии

ASP.NET Core Web API на .NET 10, Entity Framework Core с PostgreSQL (Npgsql), авторизация по JWT, Swagger в режиме разработки. Страница сайта лежит в `wwwroot/index.html` и работает с тем же API. Для выкладки сайт собирается в Docker-контейнер.

## Устройство репозитория

В `Controllers` лежат конечные точки API по темам (авторизация, книги, полка, клубы, отборы, голоса, рецензии, пользователи, админка), в `Models` и `Data` модель данных и контекст базы, в `Migrations` миграции, в `Dtos` объекты запросов и ответов, в `Services` выпуск токенов.
